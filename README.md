# Workflow Automation Assistant

Workspace for handing daily work to Claude Code.

- `CLAUDE.md` – standing instructions Claude reads every session
- `workflows/` – one file per workflow (start from `_TEMPLATE.md`), plus `CONNECTORS.md`
- `.claude/skills/` – reusable playbooks Claude loads when relevant
- `.claude/agents/` – specialist subagents with their own tools and instructions
